Örnek yazı. Hem mobil hem web tarafında React kullanmak, bir projeden diğerine geçerken zihinsel bağlam değiştirme maliyetini neredeyse sıfıra indiriyor.

## Paylaşılan tipler

Aynı TypeScript tiplerini istemci ve sunucu arasında paylaşmak, hataların derleme anında yakalanmasını sağlıyor:

```ts
export type Card = { suit: "maça" | "kupa" | "karo" | "sinek"; rank: number };

export function isPisti(table: Card[], played: Card): boolean {
  return table.length === 1 && table[0].rank === played.rank;
}
```
